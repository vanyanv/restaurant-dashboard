# The Ask Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `/dashboard/ask` and `/m/ask` match `docs/counter/ask-page-mock.html` — rail actions, turn footers, stop, the composer, the empty state, the phone sheet.

**Architecture:** Every piece extends what exists: the rail component grows a menu and inline actions that call the thread-actions server actions; the route stamps per-turn metadata on the message so cost/seconds/thumbs work live, and the adapter joins the same figures from `ChatTurn` for restored turns; `useAsk` exposes `stop` and a `stopped` state; the composer becomes a textarea with a slash menu and a send↔stop button. New CSS goes in `src/styles/counter-repairs.css` under the "ADDITION" convention (`counter-components.css` is generated — never edit it).

**Tech Stack:** Next.js 16, React 19, AI SDK 6 (`useChat`, `toUIMessageStreamResponse({ messageMetadata })`), Prisma 7, Playwright for the browser check.

**Spec:** `docs/superpowers/specs/2026-09-05-ask-page-design.md` (and the mock it names).

## Global Constraints

- No colour literal outside `counter.css`; no generic Tailwind colour; no page importing Prisma or a server action directly (`npm run tokens` fails the build otherwise). Server actions live in `src/lib/counter/actions/`.
- `counter-components.css` is GENERATED. All new CSS goes in `counter-repairs.css` with a comment that says it is an addition and what it borrows from.
- Build-velocity rule: no new test files. The gate is `npm run tokens && npx tsc --noEmit --incremental false && npm run build`, plus a browser comparison against the mock.
- Commit by explicit path (`git add <files>`), never `git add -A`.
- Copy: no em dashes in UI strings where the mock uses "·"; captions are JetBrains Mono uppercase via the existing `.rk` / `.cvgrp` classes.
- D7: nothing dead ships. Do not render Save-as-question, priorq recall, photo attach.

```ts
/** What a thumbs-down asks. The value is what `ChatTurn.feedback` stores. */
export const ASK_DOWN_REASONS = [
  { code: "down:number", label: "Wrong number", hint: "a figure does not match a page" },
  { code: "down:scope", label: "Wrong scope", hint: "answered a different store or week" },
  { code: "down:refused", label: "Refused wrongly", hint: "it could have answered" },
  { code: "down:slow", label: "Too slow", hint: "right, but not worth the wait" },
] as const

export type AskFeedback = "up" | (typeof ASK_DOWN_REASONS)[number]["code"]

export function isAskFeedback(v: unknown): v is AskFeedback {
  return v === "up" || ASK_DOWN_REASONS.some((r) => r.code === v)
}
```

- [ ] **Step 2: Add the three actions to `src/lib/counter/actions/conversation.ts`**

```ts
import { deleteAllConversations, forkConversation } from "@/lib/chat/conversation"
import { isAskFeedback, type AskFeedback } from "@/lib/counter/ask-feedback"

export async function deleteAllAskThreads(): Promise<Result<{ deleted: number }>> {
  const session = await getServerSession(authOptions)
  if (!session?.user) return { ok: false, error: "Not signed in" }
  try {
    const deleted = await deleteAllConversations(chatPrisma, session.user.accountId)
    return { ok: true, deleted }
  } catch (err) {
    return { ok: false, error: describe(err) }
  }
}

export async function forkAskThread(input: {
  id: string
  throughMessageId: string
}): Promise<Result<{ id: string }>> {
  const session = await getServerSession(authOptions)
  if (!session?.user) return { ok: false, error: "Not signed in" }
  try {
    const fork = await forkConversation(
      chatPrisma,
      session.user.id,
      session.user.accountId,
      input.id,
      input.throughMessageId,
    )
    return { ok: true, id: fork.id }
  } catch (err) {
    return { ok: false, error: describe(err) }
  }
}

export async function rateAskTurn(input: {
  chatTurnId: string
  feedback: AskFeedback | null
}): Promise<Result<object>> {
  const session = await getServerSession(authOptions)
  if (!session?.user) return { ok: false, error: "Not signed in" }
  if (input.feedback !== null && !isAskFeedback(input.feedback)) {
    return { ok: false, error: "That is not a rating" }
  }
  // Ownership travels through the conversation: a turn on another account's
  // thread does not exist for this one.
  const turn = await chatPrisma.chatTurn.findFirst({
    where: { id: input.chatTurnId, conversation: { accountId: session.user.accountId } },
    select: { id: true },
  })
  if (!turn) return { ok: false, error: "That turn no longer exists" }
  await chatPrisma.chatTurn.update({ where: { id: turn.id }, data: { feedback: input.feedback } })
  return { ok: true }
}
```

Check `session.user.id` is the owner id the route uses (`route.ts` reads `ownerId` from the session — copy the exact property it uses). Check `ChatTurn` has a `conversation` relation in `prisma/schema.prisma`; if it only has `conversationId`, use `where: { id, conversationId: { in: (await chatPrisma.conversation.findMany({ where: { accountId }, select: { id: true } })).map(c => c.id) } }` instead.

```ts
export interface AskTurnMeta {
  chatTurnId: string | null
  costUsd: number | null
  durationMs: number | null
  feedback: string | null
}

/** The metadata the route stamps on the assistant message at `finish`. */
export function readAskTurnMeta(metadata: unknown): AskTurnMeta | null {
  if (!metadata || typeof metadata !== "object") return null
  const m = metadata as Record<string, unknown>
  if (typeof m.chatTurnId !== "string") return null
  return {
    chatTurnId: m.chatTurnId,
    costUsd: typeof m.costUsd === "number" ? m.costUsd : null,
    durationMs: typeof m.durationMs === "number" ? m.durationMs : null,
    feedback: typeof m.feedback === "string" ? m.feedback : null,
  }
}
```
